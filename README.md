## 🛠️ How to Compile & Run

Using **g++** (recommended):

```bash
g++ filename.cpp -o output
./output
```

Example:
```bash
cd Q01_Average
g++ average.cpp -o average
./average
```

On **Windows** (MinGW):
```bash
g++ average.cpp -o average.exe
average.exe
```

> Some files use `<cmath>` — add `-lm` if needed on Linux.
